# Headline Patterns

## 목적

이 문서는 `ybchar.dev` 기술 글 제목을 어떻게 잡아야 하는지 정리합니다.

## 우선 패턴

### 1. 기술명 + 과정/사용기

적합한 경우:
- 마이그레이션
- 도입기
- 외부 서비스 연동
- 운영 도구 사용기

예시:
- `Java 21, Spring boot 3.4.x 마이그레이션 과정`
- `LocalStack과 DynamoDB 사용기`

### 2. 짧은 훅 + 주제 + `에 대해`

적합한 경우:
- 패턴 소개
- 설계 원리 설명
- 비교형 설명

예시:
- `소프트웨어 디자인도 전략적으로, 전략 패턴에 대해`

### 3. 왜 ... 인가

적합한 경우:
- 설계 선택 이유
- 트레이드오프 설명
- 오해하기 쉬운 결정 정리

예시:
- `TSID는 왜 사용하는가`

## 제목 작성 규칙

- 제목만 봐도 어떤 기술과 범위를 다루는지 보여야 합니다
- 기술명 없이 추상적인 카피만 남는 제목은 피합니다
- 낚시성 수식어보다 주제를 선명하게 드러냅니다
- 가능하면 `기술명 + 맥락 + 선택 이유` 가 드러나게 씁니다

## 좋은 예

- `Redis Lua로 상태 전이를 묶은 과정`
- `Spring Boot 3.x 마이그레이션 과정`
- `왜 JPA에서 ID 전략을 다시 고민했는가`

## 피해야 할 예

- `대규모 트래픽을 해결한 비밀`
- `놀라운 성능 개선 이야기`
- `백엔드 개발자가 꼭 알아야 할 것`
